# QBank KBC × 21CLD

Production-oriented question bank engine for Indonesian education.

QBank ini dirancang sebagai reference implementation untuk pengelolaan bank soal yang dapat memetakan:

- Kurikulum Merdeka
- Kurikulum Madrasah
- CP
- TP
- Elemen
- Fase
- Kelas
- Mata pelajaran
- Level kognitif
- Tingkat kesulitan
- Bentuk soal
- 21st Century Learning Design (21CLD)
- Kurikulum Berbasis Cinta (KBC)
- Metadata referensi
- Blueprint assessment

Repository ini memisahkan:

1. Question Library
2. Curriculum Reference
3. Framework Reference
4. Validation Engine
5. Mapping Engine
6. Blueprint Engine
7. REST API
8. CLI
9. Automated Tests
